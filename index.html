End-to-End Encrypted (AES-GCM 256-bit)

Lahat ng files at detalye ay ine-encrypt gamit ang iyong master key bago i-upload sa cloud. Walang makakabasa nito maliban sa iyo.

📖 Paano kumuha ng libreng Supabase URL & Key (1 minuto lang)
  1. Pumunta sa supabase.com at mag-sign up nang libre.
  2. Pindutin ang "New Project" at pumili ng database password.
  3. Pumunta sa Project Settings > API at kopyahin ang Project URL at anon / public key.
  4. Pumunta sa SQL Editor sa Supabase at i-run ang sumusunod na code para sa vault table:
CREATE TABLE IF NOT EXISTS keepsafe_vault (
  user_id TEXT PRIMARY KEY,
  encrypted_data TEXT,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);
ALTER TABLE keepsafe_vault ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow anon access" ON keepsafe_vault FOR ALL USING (true) WITH CHECK (true);
