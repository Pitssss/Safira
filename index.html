☁️ How to setup Cloudflare Worker (Free, 2 minutes)
  1. Go to dash.cloudflare.com and sign in / sign up for free.
  2. Click Workers & Pages > Create application > Create Worker.
  3. Name it (e.g. keepsafe-vault) and click Deploy.
  4. Click Edit code, clear default code, and paste the Cloudflare Worker code below:
// Cloudflare Worker for Keepsafe Vault Sync
export default {
  async fetch(request, env) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type, Authorization, X-Sync-Secret',
    };
    if (request.method === 'OPTIONS') return new Response(null, { headers: cors });
    const url = new URL(request.url);
    if (url.pathname === '/health') {
      return new Response(JSON.stringify({ status: 'ok', service: 'Keepsafe Vault' }), { headers: cors });
    }
    if (url.pathname === '/api/vault') {
      if (request.method === 'GET') {
        const uid = url.searchParams.get('user_id');
        const data = env.VAULT_KV ? await env.VAULT_KV.get('vault:' + uid) : null;
        if (!data) return new Response(JSON.stringify({ found: false }), { headers: cors });
        return new Response(JSON.stringify({ found: true, encrypted_data: JSON.parse(data) }), { headers: cors });
      }
      if (request.method === 'POST') {
        const { user_id, encrypted_data } = await request.json();
        if (env.VAULT_KV) await env.VAULT_KV.put('vault:' + user_id, JSON.stringify(encrypted_data));
        return new Response(JSON.stringify({ success: true }), { headers: cors });
      }
    }
    return new Response('Keepsafe Worker Online', { headers: cors });
  }
};
  1. Click Save and Deploy in the Cloudflare editor.
  2. (For persistent storage): Under Worker > Settings > Bindings > Bind a KV namespace named VAULT_KV.
  3. Copy the worker URL (e.g. https://keepsafe-vault.yourname.workers.dev) and paste above!
📖 How to get a free Supabase URL & Key
  1. Go to supabase.com and sign up for free.
  2. Click "New Project" and set a database password.
  3. Go to Project Settings > API and copy the Project URL and anon / public key.
  4. Go to SQL Editor in Supabase and run this code to create the vault table:
CREATE TABLE IF NOT EXISTS keepsafe_vault (
  user_id TEXT PRIMARY KEY,
  encrypted_data TEXT,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);
ALTER TABLE keepsafe_vault ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow anon access" ON keepsafe_vault FOR ALL USING (true) WITH CHECK (true);
